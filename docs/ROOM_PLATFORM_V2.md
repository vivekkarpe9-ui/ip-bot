# iP Bot Work Room Platform V2

## Dynamic rooms

Rooms are user-created workspaces, not a fixed list. A room has a name, purpose, icon, agents, teams, workflows, tasks, files, data connections, KPIs, reports and permission rules.

## Create Work Room

Create Room → choose template or Custom → define objective → add agents/team → configure commands/tools → choose data → define workflows → set approvals → choose schedule → activate.

## Room types

Planned templates include Solar, Travel, Shopping/Fashion, HR, Call Centre, Marketing, Finance, Operations, Construction, Manufacturing, Logistics, Real Estate, Education, Digital Agency and Custom Business.

## Room dashboard

Show active agents, running tasks, approvals, customer/lead metrics, financial metrics where relevant, project progress, research reports, alerts and recent activity.

## Cross-room orchestration

The Master Agent can route tasks between rooms when the user grants access. Example: a Travel room can request marketing work from the Marketing room and financial analysis from the Finance room.

## Room permissions

Each room controls which agents, users, integrations, data sources and actions are available. Sensitive actions can require approval even when an agent is otherwise active.

## Room exports

Rooms can produce structured reports and spreadsheet-compatible exports. Gmail reporting is an integration layer, not the system of record.
