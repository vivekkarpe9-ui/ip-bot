## Design requirement
The implementation should closely reproduce the owner's supplied design language and layout while keeping iP Bot's own branding/content. The same design system should be reused across every room.

## Dynamic room requirement
A user-created Work Room can represent any useful work domain. A room can contain agents, teams, tasks, workflows, files, reports, dashboards, integrations, and business entities supported by the platform.
