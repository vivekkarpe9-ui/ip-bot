# iP Bot Product Upgrades

## Priority capabilities

1. Agent Builder 2.0
2. Agent Team Builder
3. Research Lab with source/evidence tracking
4. Scoped long-term memory
5. Agent Control Tower
6. Permission and approval center
7. Agent budgets and limits
8. Durable workflows and safe retry/recovery
9. Agent Evaluation Lab
10. Agent Factory for proposed teams/workflows
11. Reusable agent and room templates
12. Cross-room orchestration
13. Business KPI and P&L analytics
14. Gmail and spreadsheet reporting integrations
15. Website/app business factory

## Product rule

Build these as reusable platform capabilities first. Solar, Travel, Shopping, HR, Call Centre and other businesses should be room modules built on the same core engine.

## Human control

The platform can automate routine work, research, analysis, drafting and coordination. Actions with financial, legal, employment, contractual, privacy or external-publication consequences use configurable approval gates.

## Observability

Every agent run should have a traceable run ID and show inputs, outputs, tools used, status, approvals, errors, timing and cost/usage where available.
