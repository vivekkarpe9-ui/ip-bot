# iP Bot UI Design System

## Reference direction
The initial UI should closely follow the visual language shown in the owner's supplied reference videos/screenshots. The reference is the owner's own website/design, so this project may intentionally reuse that visual design direction rather than treating it as a third-party imitation.

## Core visual language
- Premium dark futuristic interface
- High-contrast typography
- Glass / translucent surfaces
- Rounded cards and panels
- Teal/cyan accent glow
- Soft depth, blur and subtle shadows
- Large, clear dashboard metrics
- Smooth micro-interactions and transitions
- Mobile-first layouts with responsive desktop support
- Consistent iconography and spacing

## App structure
### Home
- Global search
- Quick actions
- Active rooms
- Agent activity
- KPIs
- Alerts and approvals

### Rooms
The Rooms screen must support both templates and user-created rooms.

Users can:
- Create a room from a template
- Create a blank custom Work Room
- Name and describe the room
- Choose an icon/image
- Add or remove agents
- Define room-specific tasks and workflows
- Connect permitted data sources
- Set room permissions
- Archive/restore rooms

## Dynamic Work Room system
There is no fixed limit on business rooms. Any useful work domain can become a room.

Examples:
- Solar
- Travel
- Shopping/Fashion
- HR
- Call Centre
- Marketing
- Finance
- Operations
- Construction
- Manufacturing
- Logistics
- Education
- Real Estate
- Digital Agency
- SaaS
- Custom Work Room

A custom room should be able to contain any combination of agents, tasks, workflows, files, reports, dashboards, integrations and business entities supported by the platform.

## Room screen
Each room has:
- Room header
- Agent team
- Active tasks
- Workflow status
- Files/data
- Customer/business records where applicable
- Analytics
- Approvals
- Activity timeline
- Room settings

## Agent presentation
Agents appear as visual cards with:
- Name
- Role
- Status
- Current task
- Permission level
- Last activity
- Open workspace action

## Design rule
The design must feel like one coherent premium iP Bot operating system. Business-specific rooms may have different icons and accent treatments, but should retain the same core layout, navigation, cards, typography, spacing and interaction patterns.

## UX principles
- Fast mobile navigation
- Minimal clutter
- Important actions visible without deep menus
- Clear distinction between AI-generated suggestions and approved actions
- Approval states are visually obvious
- Every important agent action can be inspected from the activity timeline
