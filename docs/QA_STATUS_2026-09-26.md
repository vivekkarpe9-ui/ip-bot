# iP Bot QA Status — 2026-09-26

- `app/index.html` loads the CSS and JS assets using relative paths.
- `app/app.js` contains the current room rendering and create-room flow.
- Custom rooms now persist through browser `localStorage`.
- Room names are escaped before being inserted into the DOM.

- Room count is recalculated from the current room list.
- Room cards support keyboard Enter activation.
